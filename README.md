# 💸 Dondevem? Dondevai? Versão 0.1.7 (Projeto em Alpha)

> Um aplicativo de controle financeiro pessoal.

O **Dondevem? Dondevai?** foi desenvolvido para responder às duas perguntas mais importantes da sua vida financeira de forma clara e interativa."

---

## ✨ Funcionalidades Principais

* 🔒 **Privacidade Local First:** Zero dependência de servidores externos. Seus dados financeiros são salvos localmente usando `AsyncStorage`.
* 📊 **Dashboard Dinâmico:** Resumo do mês com contadores numéricos animados fluindo em tempo real.
* 🏆 **Ranking de Gastos (Drill-down):** Descubra para onde seu dinheiro está indo com um "Top Tier" expansível que detalha categorias e subcategorias.
* 🗑️ **Gestos Nativos (Swipe):** Arraste transações para a esquerda para apagá-las rapidamente, garantindo uma experiência premium de navegação.
* 🎉 **Animações de Recompensa:** Integração com Lottie Animations para celebrar novos ganhos registrados.
* 🔍 **Histórico Inteligente:** Filtros avançados por período e tipo de transação (Entradas/Saídas).

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído com as melhores e mais modernas ferramentas do ecossistema mobile:

* **[React Native](https://reactnative.dev/):** Framework principal.
* **[Expo & Expo Router](https://expo.dev/):** Ambiente de desenvolvimento e roteamento de telas baseado em arquivos.
* **[React Native Reanimated](https://docs.swmansion.com/react-native-reanimated/):** Para animações fluidas a 60fps rodando diretamente na UI thread.
* **[React Native Gesture Handler](https://docs.swmansion.com/react-native-gesture-handler/):** Para interações táteis (Swipe to delete).
* **[Lottie React Native](https://lottiefiles.com/):** Para renderização de animações vetoriais leves e de alta qualidade.
* **AsyncStorage:** Banco de dados local.
